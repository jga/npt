# Security policy

## Reporting a problem

Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a
vulnerability"). Do not open a public issue for a security problem.

## What counts

- Anything that makes `copier copy` or `copier update` run code on a consumer's machine.
- Anything that writes a secret or personal data into a generated project.
- Anything that overwrites a project-owned file on update.
